## 1. 가림 — 저장 전

```python
from app.agent.sensitive import mask_notices, mask_secrets

m = mask_secrets(content)   # IQ-01·IQ-08 content, IQ-09 comment, TK-03 초안 수정 글
m.text                      # 저장할 글      '비밀번호는 ●●●●●● 인데'
m.counts                    # 유형별 개수    {'PASSWORD': 1}
mask_notices(m)             # 안내 문구 목록 (가린 게 없으면 [])
```

**결과 쓰는 법**

| 값 | 어디에 |
|---|---|
| `m.text` | `messages.content`·초안에 저장. **원래 글 대신 이것만** 저장·판단·전달 |
| `m.counts` | 유형마다 `audit_logs` `SENSITIVE_INPUT` 한 줄 (5.2) |
| `mask_notices(m)` | 응답 `messages`에 `SYSTEM` 메시지로 하나씩 (6.1) |

**기록 유형** (`m.counts`의 키)

| 등급 | 유형 |
|---|---|
| A 비밀정보 | `PASSWORD` · `OTP` · `API_KEY` · `PRIVATE_KEY` |
| B 고유식별·금융 | `RRN` · `CARD` · `ACCOUNT` |

**안내 문구**

| 상황 | 쓸 것 |
|---|---|
| 일반 글을 가림 | `mask_notices(m)` |
| TK-03 초안 수정 글을 가림 | `MASK_NOTICE_DRAFT` 하나 |
| 근거가 모두 차단됨 | `BLOCKED_NOTICE` |

> 문구는 화면 `mask.ts`와 **글자까지 같습니다.** 한쪽만 바꾸면 시험이 실패합니다.

**지켜야 할 것**
- 원래 글은 저장하지도, 로그에 찍지도 않습니다 (5.3 ①②).
- 가린 값은 결과 어디에도 남지 않습니다. `counts`에는 유형과 개수만 있습니다.
- ⚠️ **오류가 나면 저장하지 않고 `500`으로 응답합니다 (3.3).** 이 함수는 오류를 숨기지 않습니다.

## 2. 치환 — Claude에 보내기 직전

```python
from app.agent.sensitive import Pseudonymizer

p = Pseudonymizer(직원_이름_목록)          # users.name. Claude를 부를 때마다 새로 만든다
history = [p.apply(t) for t in 이전_대화]   # ① 이전 대화부터
message = p.apply(이번_글)                  # ② 이번 글 순서로
```

| 바뀌는 것 | 예 |
|---|---|
| 직원 이름 | `김민지` → `[직원1]` |
| 전화번호 (휴대폰·유선) | `010-1234-5678`, `02-1234-5678` → `[전화번호1]`, `[전화번호2]` |
| 이메일 | `minji.kim@ict.example` → `[이메일1]` |
| 사번 | `EMP-1001` → `[사번1]` |

**번호 매기는 법**
- 처음 나온 순서대로 1부터 매깁니다. 이전 대화와 이번 글에서 **같은 사람은 같은 번호**입니다.
- 같은 번호를 다르게 써도 같은 사람으로 봅니다 (`010-1234-5678` = `01012345678`).

**지켜야 할 것**
- **대응표는 밖으로 내보내지 않습니다.** 호출이 끝나면 `p`를 버립니다.
- AI 답변을 원래 이름으로 되돌리지 않습니다 (3.1).
- DB에 저장하는 글에는 쓰지 않습니다. C·D는 담당자 업무에 필요해서 DB에는 그대로 둡니다 (3.2).
- ⚠️ **오류가 나면 Claude를 부르지 않고 담당자 연결 제안으로 넘깁니다** (3.3, 09 T11).

## 3. 근거 거르기 — Claude에 보내기 직전

```python
from app.agent.sensitive import filter_evidence

f = filter_evidence(검색결과.documents, 검색결과.legacy, p)   # p: 2번에서 쓴 Pseudonymizer 그대로
```

**정책별 처리**

| `transfer_policy` | 처리 |
|---|---|
| `ALLOWED` | 그대로 |
| `MASKED` | 가림 + 치환. 대상: 본문·원인·해결·제목·근거 문장 |
| `BLOCKED`, 값 없음, 모르는 값 | 뺌 |

**결과 쓰는 법**

| 값 | 뜻 | 어디에 |
|---|---|---|
| `f.documents` · `f.legacy` | 보내도 되는 근거 | Claude 입력 |
| `f.blocked` | 뺀 근거 번호 (`doc_code`·`legacy_no`) | `audit_logs` `BLOCK` · `DOC_BLOCKED` |
| `f.failed` | 그 가운데 가리다 실패한 것 | `audit_logs` `FAIL` · `FILTER_FAILED` |
| `f.all_blocked` | 결과가 있었는데 **모두** 빠짐 | `True`면 Claude를 부르지 않고 `ESCALATE` (전송제한) |

**지켜야 할 것**
- **`p`는 2번에서 쓴 것을 그대로 넘깁니다.** 그래야 이번 글의 `[직원1]`과 근거의 `[직원1]`이 같은 사람이 됩니다.
- `all_blocked`는 처음부터 결과가 없으면(근거부족) `False`입니다. 전송제한과 근거부족은 다르게 처리합니다 (08 3.2).
- `MASKED`를 가리다 실패하면 그 근거만 빼고 나머지는 계속 씁니다 (3.3).
- 가린 뒤 본문과 맞지 않게 된 근거 문장은 뺍니다. 근거 문장은 본문 안에 그대로 있어야 하기 때문입니다 (`rag/search/result.py`).
- 과거 사례 제목(`title`)도 가립니다. docs/10 4장 ④에는 없지만, 사례 제목도 사용자 글에서 나오기 때문입니다.

## 4. 로그 안전망 — 로그를 쓰기 직전

```python
import logging
from app.agent.sensitive import MaskSecretsFilter

for handler in 서버의_모든_로그_핸들러:   # 콘솔·파일 등 전부
    handler.addFilter(MaskSecretsFilter())
```

| 가리는 것 | 예 |
|---|---|
| 로그 메시지 | `사용자 글: 비밀번호는 ●●●●●●` |
| 예외 내용 (traceback) | `ValueError: 주민번호 ●●●●●● 처리 실패` |

| 남기는 것 | 이유 |
|---|---|
| traceId (UUID 모양) | 오류 원인을 이 번호로 찾습니다 (07 5.7). 끝부분이 계좌번호 규칙에 걸려 가려지던 것을 막았습니다 |

**지켜야 할 것**
- **로거가 아니라 핸들러에 붙입니다.** 로거에 붙이면 하위 로거(`app.api` 등)에서 올라온 기록은 거르지 못합니다.
- **모든 핸들러에 붙입니다.** 하나에만 붙이면 그보다 먼저 처리되는 핸들러에는 원문이 남습니다. 여러 번 붙여도 결과는 같습니다.
- 6자리 이상 숫자(문의 ID, 처리 시간 등)는 로그에서도 가려집니다. 놓치는 것보다 안전한 쪽으로 둡니다.
- 이것은 마지막 장치입니다. **요청 본문과 사용자 글을 로그에 찍지 않는 것이 먼저**입니다 (5.3 ①~③).
- A·B만 가립니다. 전화번호·이메일(C)은 로그에 그대로 남습니다.
- ⚠️ **가리다 오류가 나면 로그 내용을 지우고** `[민감정보 필터 오류로 로그 내용을 지웠습니다]`만 남깁니다 (3.3).

## 5. `mask.ts`와 다른 점

**서버 필터가 기준입니다** (docs/10 2.3). 화면(`mask.ts`)과 다른 곳은 아래 셋입니다.

| 입력 | 서버 | `mask.ts` |
|---|---|---|
| `12301012345678` (긴 숫자 안에 휴대폰 모양) | `●●●●●●` | 그대로 (뒤 `01012345678`을 휴대폰으로 보고 남겨, 앞 `123`도 가려지지 않음) |
| `02-1234-5678` (유선 전화) | 그대로 (C 등급) | `●●●●●●` (계좌번호로 봄) |
| `PIN값이 1245` (이름 뒤에 `값`·`번호`·`코드`) | `PIN값이 ●●●●●●` | 그대로 |
