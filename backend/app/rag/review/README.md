# 가이드 검증 (WBS D1~D6)

청크를 DB에 넣기(M2-2-1) 전에, 맡은 가이드를 사람이 한 번 확인하는 도구입니다. WBS 완료 기준은 문서마다 세 가지입니다.

1. 파싱 결과가 원문과 같은지
2. 분류·열람 권한이 맞는지
3. 검색 질문 3개와 정답 근거

정리본(`dataset/guides`)은 원천 JSON에서 만든 문서라, 1번의 글자 단위 대조는 `tests/check_guides.py`가 이미 합니다 (57종 × 4형식 구조·내용 일치). 사람은 **청크가 항목을 제대로 묶었는지**와 **질문 쓰기**에 시간을 씁니다.

## 하는 법

저장소의 `backend` 폴더에서 실행합니다.

```bash
# 1) 맡은 문서로 시트와 질문 양식을 만든다 (dataset/guide_review/D1_검증시트.md, D1_질문.csv)
python -m app.rag.review sheet IT-ACC-001 IT-ACC-002 IT-ACS-001 --name D1
python -m app.rag.review sheet --category SEC --name D6        # 분류 하나 전체

# 2) 단위 본문을 원문과 비교할 미리보기 (커밋하지 않는 폴더에)
python -m app.rag.chunker "../dataset/guides/ACC/guide/IT-ACC-001_사내 SSO 로그인 오류 대응 가이드.md" --out ../작업대/미리보기

# 3) 질문을 쓴 뒤 점검 (오류가 0이어야 함)
python -m app.rag.review check ../dataset/guide_review/D1_질문.csv
```

다 되면 `D?_검증시트.md`, `D?_질문.csv` 두 파일을 PR로 올립니다.

같은 명령을 다시 실행해도 이미 있는 파일은 **덮어쓰지 않습니다** (채운 확인·문제 칸을 지키려고). 문서가 바뀌어 시트를 새로 만들어야 하면 `--force`를 붙입니다. 이때 시트의 확인·문제 칸은 지워지고, 질문 파일은 그대로 둡니다.

## 검증 시트

문서마다 세 부분입니다.

| 부분 | 누가 | 내용 |
|---|---|---|
| 자동 대조 | 도구 | 제목·분류·문서 유형·버전·관리 부서·짝 문서·열람 등급을 문서와 `manifest.json`에서 각각 읽어 비교, 열람 등급이 문서 유형 규칙(가이드 사내 일반, 매뉴얼 사내 제한)에 맞는지, 포함 시나리오와 항목 문의 유형이 서로 같은지(빠진 것·더 있는 것)와 분류체계(`taxonomy.json`)에 있는 코드인지, 파서 경고, `validate()`, 청크 수 기준표. ⚠ 가 있으면 원문을 보고 `문제`에 적는다 |
| 평가셋 겹침 | 도구 → 사람 | 본문·키워드에 평가셋 문의가 들어 있는지. 같은 표현이 `history.csv`·`faq.csv`에도 있으면 일반 표현이라 괜찮고, 평가셋에만 있으면 팀에 알린다 |
| 검색 단위 | 사람 | 단위(항목 3.x, 장, FAQ 하나)마다 원문과 비교해 빠진 문장·표, 순서 꼬임, 다른 항목과 섞임이 없으면 ☐ → ☑. 문제가 있으면 `문제` 칸에 적는다 |

## 검색 질문 (`D?_질문.csv`)

| 칸 | 쓰는 법 |
|---|---|
| 문서 번호 | 양식에 채워져 있음 |
| 질문 | 임직원이 챗봇에 실제로 칠 법한 말투로. 문서 제목·본문을 그대로 옮기지 않는다 |
| 정답 단위 | 시트의 단위 칸(`IT-ACC-001/item:3.2`)을 복사. 정답이 여럿이면 `;`로 잇는다 |
| 작성자 · 메모 | 자유 |

`check`가 잡는 것: 평가셋과 같은 질문(오류)·비슷한 질문(경고), 없는 단위, 같은 질문 중복, 정답 본문을 그대로 옮긴 질문(경고), 그리고 **csv에 있는 문서마다 질문 3개 미만**(비워 둔 문서는 0개로 센다). 검증 대상 문서는 `sheet`가 만든 양식의 문서 번호로 정해지므로, 양식의 행을 지우지 말고 채웁니다.

평가셋(`dataset/data/eval_inquiries.csv`) 문장은 질문에 쓰지 않습니다 (`dataset/README.md`). 이 질문들은 평가 도구(M2-2-2)에서 검색 적중률을 재는 추가 시험지로 씁니다.
