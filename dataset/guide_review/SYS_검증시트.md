# 가이드 검증 시트 SYS

> `python -m app.rag.review sheet` 로 만든 파일입니다. 표 위쪽(자동 대조)은 도구가 채우고, **확인** 칸과 **문제** 칸은 검증자가 채웁니다.

검증 순서 (문서마다)

1. **자동 대조**에 ⚠ 가 있으면 원문(pdf)을 보고 어느 쪽이 맞는지 `문제` 칸에 적습니다.
2. **검색 단위**의 경계를 봅니다. 빠짐·순서는 자동 대조의 "단위 본문 ↔ 파싱 결과" 줄이 이미 확인합니다. 사람은 단위 하나가 한 상황을 온전히 담는지(절차 중간에서 잘리지 않음, 다른 항목 내용이 섞이지 않음, FAQ 질문과 답이 한 단위)만 보고 ☐ 를 ☑ 로 바꿉니다. 확인한 사람을 `문제` 칸에 적어도 됩니다. 단위 본문은 `python -m app.rag.chunker <md 파일> --out <폴더>` 미리보기로 봅니다.
3. **평가셋 겹침**이 있으면 그 표현이 `dataset/data/history.csv`·`faq.csv`에도 있는지 봅니다. 있으면 일반 표현이라 괜찮고, 평가셋에만 있으면 고치도록 팀에 알립니다 (평가셋 문장은 검색 자료에 넣지 않음).
4. `SYS_질문.csv` 에 검색 질문을 3개 이상 쓰고 `python -m app.rag.review check` 로 점검합니다.
