# 개발·검증 서버 접근권한 가이드

> IT-ACS-002 | v0.2 | 2026-10-12 | 임직원용 · 사내 일반

관리 부서: 시스템인프라팀

교육 프로젝트용 가상 문서이며 실제 회사의 공식 정책·절차가 아닙니다.

## 신청서 작성과 제출

### 개발·검증 서버 권한 신청서

신규 신청, 작업 범위 변경, 기간 연장에 사용합니다.

| 작성 항목 | 작성할 내용 |
| --- | --- |
| 신청 구분 · 사용할 사람 | 신규 / 변경 / 연장, 이름·사번·부서 |
| 프로젝트 · 환경 | 업무명, 개발 또는 검증, 사내 또는 고객사 자원 |
| 서버 · DB · 필요한 작업 | 자원 식별정보와 조회·실행·배포 등 실제 수행할 작업 |
| 신청 이유 · 기간 | 업무 사유, 시작 희망일과 종료 희망일 |
| 기존 신청 · 승인 | 기존 신청번호와 확인 가능한 승인 기록이 있으면 기재 |

> 비밀번호·개인키·토큰은 적지 마세요. 자원 주소가 민감하면 담당자가 안내한 보호된 경로로 전달하세요.

### 신청서는 이렇게 작성하세요

예시: 프로젝트 검증 결과를 확인하기 위한 조회 권한 신청

**환경과 자원을 구분**

개발·검증 중 어디에 접속할지 적고, 서버 또는 DB와 프로젝트를 함께 적습니다.

**필요한 작업만 작성**

“모든 권한” 대신 조회·실행 등 필요한 작업과 이유를 적습니다. 사용 기간은 실제 업무 일정에 맞춥니다.

**승인 요청 후 번호 보관**

그룹웨어 > IT 요청 > 권한 신청에서 제출합니다. 필요한 승인 경로를 확인하고 신청번호를 보관합니다.

> 화면은 가상 예시입니다. 해당 양식이 없거나 승인자가 불명확하면 서비스데스크 또는 자원 담당자에게 확인하세요.

### 기존 권한 변경·기간 연장

신청만으로 권한이나 사용 기간이 바뀌지는 않습니다.

**기존 신청 연결**

기존 신청번호, 현재 권한·종료일과 새로 필요한 권한·기간을 함께 적습니다.

**변경 범위 승인 확인**

새 작업과 연장 사유를 설명합니다. 운영·고객사·관리자 권한은 자원별 승인 경로를 확인합니다.

**처리 후 다시 확인**

반영 완료 안내 후 승인된 환경과 기능만 확인합니다. 만료 중에는 동료 계정으로 대신 접속하지 않습니다.

> 기간이 정해진 권한은 종료일 전에 유지 필요 여부를 확인하고, 더 필요하지 않으면 회수를 요청하세요.

## 접속 확인과 오류 문의

### 반영 완료 후 접속 확인

승인된 접속 경로와 본인 계정을 사용합니다.

**접속 조건 확인**

담당자가 안내한 접속 도구·대상 환경·계정을 확인합니다. 재택·외부 접속은 회사 VPN 사용 조건을 확인합니다.

**승인된 작업 확인**

처리 완료 안내 후 접속과 허용된 작업을 확인합니다. 개발 권한으로 운영 환경에 시험 접속하지 않습니다.

**결과 전달**

정상 사용 여부를 기존 신청에 알립니다. 승인하지 않은 기능이 보이면 이용을 중단하고 담당자에게 알립니다.

> SSH 주소·포트·인증 수단은 담당자 안내를 따릅니다. 이 문서는 임의의 접속 명령이나 관리자 권한 획득 방법을 제공하지 않습니다.

### 승인 후에도 접속이 안 되나요?

SSH 실패나 시간 초과만으로 권한 부족이라고 단정하지 마세요.

**계정·환경·반영 확인**

신청한 자원인지, 승인만 완료인지 실제 반영까지 완료인지 확인합니다. VPN 상태도 확인합니다.

**오류와 영향을 기록**

오류 문구·발생 시각·마지막 정상 시각·영향 인원·중단 작업·마감을 적습니다.

**기존 요청으로 문의**

이미 시도한 조치와 결과를 전달합니다. 권한 외에 네트워크·서버·저장공간 문제일 수 있어 담당자 확인이 필요합니다.

> 재접속을 반복하거나 방화벽·보안 기능을 끄지 마세요. 서버 재시작·디스크 정리는 사용자 조치 범위가 아닙니다.

## 주의사항과 문의

### 자주 묻는 질문

계정 대여나 보안 우회는 대체 방법이 아닙니다.

| 질문 | 안내 |
| --- | --- |
| 급한 배포인데요? | 중단 업무와 마감을 알려 우선순위 검토를 요청합니다. 승인 없이 권한을 확대하지 않습니다. |
| 개인키를 보내야 하나요? | 아니요. 개인키·토큰은 보내지 않습니다. 공개키가 필요하면 담당자가 확인한 제출 경로만 사용합니다. |
| 프로젝트가 연장됐어요. | 기존 권한도 자동 연장된다고 가정하지 말고 기간 변경 승인을 확인합니다. |
| 고객사·운영 서버는요? | 사내 개발·검증 권한과 별개입니다. 소유 조직의 승인 절차를 확인합니다. |

> 관리 부서: 시스템인프라팀. VPN·망 문제는 네트워크팀, 침해 의심은 정보보안팀과 연계합니다.

### 문의할 때 전달할 정보

사내 공지된 서비스데스크 또는 기존 자원 담당자에게 전달합니다.

**접속 대상과 기존 기록**

본인 계정 식별정보, 프로젝트, 환경·자원, 신청번호, 승인·반영 상태를 알려 주세요.

**증상과 업무 영향**

오류·시각·이미 해 본 방법·결과, 영향 인원·중단 업무·마감·허용된 대체 방법을 전달합니다.

**보안 의심은 즉시 신고**

도용·무단 접근·자료 노출이 의심되면 일반 권한 신청을 기다리지 말고 정보보안팀 또는 서비스데스크에 알립니다.
