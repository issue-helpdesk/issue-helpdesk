# 퇴사·부서이동 권한 변경 가이드

> IT-ACS-003 | v0.2 | 2026-10-12 | 임직원용 · 사내 일반

관리 부서: 업무시스템팀 · 자원별 담당

교육 프로젝트용 가상 문서이며 실제 회사의 공식 정책·절차가 아닙니다.

## 부서이동 변경 요청

### 권한 변경 요청서

대상 임직원·팀장·인사 담당자는 확인된 인사 정보를 바탕으로 요청합니다.

| 작성 항목 | 작성할 내용 |
| --- | --- |
| 대상자 · 변경 종류 | 이름·사번, 부서이동 / 퇴사 / 인사 일정 변경 |
| 인사 근거 · 적용 일시 | 확인 가능한 인사 기록 참조와 적용 일시 |
| 기존 업무 → 새 업무 | 기존·변경 부서와 직무. 부서이동인 경우 작성 |
| 변경할 자원 · 기능 | 회수할 권한 / 새로 필요한 권한 / 유지 검토가 필요한 권한 |
| 자료 인계 · 관련 기록 | 인계 대상·인수자, 승인 기록과 기존 신청번호 |

> 퇴사 사유·평가 등 권한 처리에 불필요한 인사정보는 쓰지 않습니다. 모르는 자원은 담당자에게 확인을 요청하세요.

### 부서이동 요청 작성 예시

새 업무 권한과 기존 권한 정리를 함께 요청합니다.

**발령 정보 기재**

확인된 발령일과 기존·새 부서, 직무를 적습니다. 근거 기록은 필요한 참조 정보만 전달합니다.

**권한별로 구분**

새로 필요한 기능과 회수할 기능을 적습니다. 인수인계로 유지가 필요하면 사유·기간을 적어 승인을 확인합니다.

**제출·처리 상태 확인**

그룹웨어 권한 신청 경로로 요청하고 번호를 보관합니다. 해당 양식이 없으면 서비스데스크에 안내를 요청합니다.

> 부서이동 통지만으로 모든 시스템의 권한이 자동 변경되었다고 보지 않습니다.

### 이동 후 새 폴더가 보이지 않나요?

인사 반영, 새 권한 부여, 기존 권한 회수는 각각 확인합니다.

**신청·반영 상태 확인**

발령일, 본인 계정, 대상 폴더·메뉴와 반영 완료 안내를 확인합니다.

**안전한 확인 1회**

작업을 저장한 뒤 재로그인합니다. 이미 해 봤다면 반복하지 말고 결과를 알려 주세요.

**기존 신청에 추가 문의**

신청번호, 오류·발생 시각, 막힌 업무·마감을 전달합니다. 다른 부서 자료가 보이면 열람을 중단하고 신고합니다.

> 새 폴더가 열린다고 기존 권한 회수까지 완료된 것은 아닙니다. 회수 결과는 담당자가 확인합니다.

## 퇴사와 자료 인계

### 퇴사 관련 요청 작성 예시

확인된 인사 정보와 실제 사용 자원을 기준으로 요청합니다.

**인사 확인 정보 전달**

대상자와 인사 담당자가 확인한 적용 일시를 전달합니다. 퇴사자의 계정으로 대신 로그인하지 않습니다.

**업무·자료 인계 정리**

인계할 자료와 인수자를 정하고 필요한 승인을 확인합니다. 개인 계정이나 비밀번호 자체를 넘기지 않습니다.

**담당자에게 회수 확인**

서비스데스크 또는 기존 담당자에게 요청번호로 확인합니다. 계정 차단과 시스템별 회수 결과를 구분합니다.

> 메일 자동 전달·자료 삭제·외부 반출은 임의로 실행하지 않습니다. 자료 보존·이관은 담당자가 승인 범위를 확인해 처리합니다.

### 일정이 바뀌거나 예외가 생기면

기존 요청과 연결하여 변경 내용을 알려 주세요.

**발령·퇴사 일정 변경 또는 취소**

기존 신청번호, 변경 전후 일시와 확인 가능한 인사 기록을 전달합니다. 예약 변경 완료를 담당자에게 확인합니다.

**휴직·복직·겸무**

퇴사나 일반 이동과 동일하게 처리된다고 가정하지 않습니다. 인사 부서와 자원 담당자에게 적용 범위를 확인합니다.

**퇴사 후 접속·권한 잔존 의심**

의심 시각과 이미 확인한 사실만 신고합니다. 추가 로그인·열람으로 시험하지 말고 정보보안팀 또는 서비스데스크에 즉시 알립니다.

> 다른 사람의 말만으로 계정을 차단·복원할 수 없습니다. 확인된 인사 근거와 자원별 승인 절차가 필요합니다.

## 결과 확인과 문의

### 변경 완료는 이렇게 확인하세요

사용자와 담당자의 확인 역할을 구분합니다.

| 상황 | 확인 방법 |
| --- | --- |
| 새 업무 권한 | 이동한 임직원이 본인 계정으로 승인된 기능의 사용 여부를 확인합니다. |
| 기존 권한 회수 | 담당자가 자원별 설정·잔존 접근을 확인합니다. 사용자가 민감자료를 열어 시험하지 않습니다. |
| 자료 인계 | 지정 인수자가 승인된 자료를 사용할 수 있는지 확인합니다. |
| 일부만 처리됨 | 미완료 자원과 다음 안내 일정을 담당자에게 확인합니다. 전체 완료로 간주하지 않습니다. |

> 퇴사자가 해결 확인을 할 수 없으면 요청을 진행한 인사·팀 담당자가 담당자 결과를 확인합니다. 시스템의 종료 권한은 별도 운영 정책을 따릅니다.

### 자주 묻는 질문과 문의 항목

사내 공지된 서비스데스크 또는 기존 요청 담당자에게 문의합니다.

| 질문 · 항목 | 안내 |
| --- | --- |
| 다음 날 자동으로 바뀌나요? | 고정 시각을 보장하지 않습니다. 자원별 실제 반영 결과를 확인합니다. |
| 인수인계 동안 계속 써도 되나요? | 유지할 범위·기간과 승인을 확인해야 합니다. 권한이 보인다는 사실만으로 계속 사용하지 않습니다. |
| 어떤 정보를 보내나요? | 신청번호, 인사 기록 참조·적용 일시, 대상 자원, 미반영 내용, 업무 영향·마감, 시도한 조치 |
| 어떤 정보는 빼나요? | 비밀번호·인증번호, 불필요한 인사정보, 다른 사람의 상세 권한 목록 |
