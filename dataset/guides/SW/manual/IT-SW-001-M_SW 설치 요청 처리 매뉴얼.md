## 1. 개요

#### 목적

IT-SW-001로 들어오는 SW 설치 문의(승인 프로그램 설치, 미승인 프로그램 설치 요청, 설치 실패)를 서비스데스크가 안내로 끝낼지 엔드포인트지원팀·정보보안팀으로 넘길지 판단하고 같은 기준으로 처리한다.

#### 담당 범위

| 항목 | 내용 |
| --- | --- |
| 1차 처리 | 서비스데스크(L1): 소프트웨어 센터 사용 안내, 설치 실패 기본 조치 안내 |
| 2차 이관 | 엔드포인트지원팀(L2): 원격 설치, 승인 목록 등록 / 정보보안팀: 미승인 프로그램 보안 검토 |
| 배정 기준 | SW-01: SW 설치·라이선스 담당 (도진우, 현현정). 재배정은 엔드포인트지원팀장이 승인 |
| 관련 시스템 | 소프트웨어 센터 관리 화면, 회사 승인 SW 목록, 원격 지원 도구, 요청 현황 |

## 2. 접수·분류 기준

임직원용 가이드의 항목별 기본값입니다. 긴급도 기준은 IT-STD-001 IT 서비스 운영 기준을 따릅니다.

| 번호 | 문의 유형 | 증상·요청 | 기본 긴급도 | 1차 처리 | 처리 방식 | 이관 대상 |
| --- | --- | --- | --- | --- | --- | --- |
| 3.1 | SW-01 | 승인 프로그램 설치 문의 (관리자 권한 없음) | P4 | 서비스데스크 | 즉시 처리 후 필요 시 티켓 | 엔드포인트지원팀 |
| 3.2 | SW-01 | 미승인 프로그램 설치 요청 (보안 검토) | P4 | 엔드포인트지원팀 | 티켓 | 정보보안팀 (보안 검토) |
| 3.3 | SW-01 | 소프트웨어 센터 설치 실패·대기 | P4 | 서비스데스크 | 즉시 처리 후 필요 시 티켓 | 엔드포인트지원팀 |

#### 처리 방식

- 즉시 처리: 안내만으로 끝낸 건. 티켓 없이 상담 기록만 남긴다.
- 티켓: 담당자 조치가 필요한 건. 담당 팀에 배정하고 상태를 RDY → WIP → FIN → CLS 로 관리한다. FIN은 담당자 처리 완료, CLS는 문의자가 해결을 확인한 최종 종료다.

#### 긴급도 조정 조건

- SW-01은 기본 P4다. 마감·고객 미팅처럼 당일 업무 차질을 말하면 한 단계 올린다 (MAN-00 공통 규칙 6).
- 수상한 설치 파일을 이미 실행했으면 SEC-02로 보고 정보보안팀에 바로 넘긴다 (IT-SEC-002-M).
- 사용자에게 관리자 권한을 주는 방식으로 해결하지 않는다.

## 3. 증상별 처리 절차

### 3.1 승인 프로그램 설치 문의 (관리자 권한 없음)

**문의 유형** SW-01 · **기본 긴급도** P4 · **1차 처리** 서비스데스크 · **처리 방식** 즉시 처리 후 필요 시 티켓 · **이관 대상** 엔드포인트지원팀

**접수 시 확인 질문**

- 어떤 프로그램인가요? 소프트웨어 센터에서 검색해 봤나요?
- 화면에 관리자 이름·암호 창이 떴나요?
- 인터넷에서 받은 설치 파일을 실행했나요?

**판단 기준**

- 즉시 처리: 소프트웨어 센터에 있으면 [설치] 방법을 안내하고 상담 기록만 남긴다 (IT-SW-001 3.1).
- 티켓: 소프트웨어 센터 설치가 실패하거나 플러그인처럼 원격 설치가 필요하면 엔드포인트지원팀에 배정한다 (INQ-2026-00081, 00150).
- 전환: 목록에 없으면 3.2, [설치 요청] 표시면 IT-SW-002-M 3.1.


#### 처리 절차

1. 소프트웨어 센터 검색 결과를 함께 확인한다.
2. 있으면 [설치]를 안내한다. 관리자 권한은 주지 않는다 (MAN-00 공통 규칙 3).
3. 설치가 실패하면 원격 지원 도구로 접속해 소프트웨어 센터 로그와 저장 공간을 확인한 뒤 원격으로 설치한다.
4. 사용자가 실행한 외부 설치 파일이 있으면 지우게 하고, 수상하면 정보보안팀에 알린다.
5. 설치를 확인하고 FIN 처리한다.

#### 처리 후 안내 문구

> 소프트웨어 센터에 있는 프로그램이라 원격으로 설치해 드렸습니다. 다음부터는 IT-SW-001 3.1에 따라 소프트웨어 센터에서 직접 설치할 수 있습니다.

**재발 방지**

- 신규 입사자 안내에 소프트웨어 센터 사용법 포함 (FAQ-036)

**이관 시 전달 정보**

- 프로그램 이름
- 소프트웨어 센터 검색 결과
- 오류 메시지·로그


### 3.2 미승인 프로그램 설치 요청 (보안 검토)

**문의 유형** SW-01 · **기본 긴급도** P4 · **1차 처리** 엔드포인트지원팀 · **처리 방식** 티켓 · **이관 대상** 정보보안팀 (보안 검토)

**접수 시 확인 질문**

- 요청서 번호(REQ-)가 있나요?
- 프로그램 이름·버전·제조사와 공식 다운로드 주소는?
- 무료/유료, 개인 무료 조건은 아닌가요?
- 사용 목적과 빈도는?

**판단 기준**

- 요청서가 없으면 IT-SW-001 3.5에 따라 제출하도록 안내한다.
- 외부 전송·원격 제어·생성형 AI·확장 프로그램은 반드시 정보보안팀 검토를 받는다.
- 유료면 라이선스 절차(IT-SW-002-M 3.1)를 함께 진행한다.


#### 처리 절차

1. 요청서 내용(이름·버전·제조사·주소·목적)을 확인하고 빠진 항목은 보완을 요청한다.
2. 정보보안팀에 보안 검토를 요청한다 (평판·악성 이력·라이선스 조건).
3. 승인되면 회사 승인 SW 목록에 등록하고 소프트웨어 센터에 올리거나 원격으로 설치한다 (INQ-2026-00088, 00194).
4. 반려되면 사유와 대체 프로그램을 안내한다.
5. 요청 현황 단계를 갱신하고 FIN 처리한다.

#### 처리 목표

접수 후 5영업일 안에 처리한다 (단순 요청 기준). 보안 검토가 길어지면 사용자에게 예상 일정을 알린다.

#### 처리 후 안내 문구

> 요청하신 프로그램의 보안 검토가 끝나 승인 목록에 등록하고 설치했습니다. 같은 프로그램은 이제 소프트웨어 센터에서 설치할 수 있습니다.

**재발 방지**

- 자주 요청되는 프로그램은 소프트웨어 센터 상시 목록에 추가

**이관 시 전달 정보**

- 요청 번호
- 프로그램 정보와 사용 목적
- 보안 검토 결과


### 3.3 소프트웨어 센터 설치 실패·대기

**문의 유형** SW-01 · **기본 긴급도** P4 · **1차 처리** 서비스데스크 · **처리 방식** 즉시 처리 후 필요 시 티켓 · **이관 대상** 엔드포인트지원팀

**접수 시 확인 질문**

- 어떤 상태에서 멈췄나요? ("대기 중", "설치 실패", "공간이 부족합니다")
- 사내망 또는 VPN에 연결돼 있나요?
- 다시 시작해 봤나요?

**판단 기준**

- 즉시 처리: IT-SW-001 3.7의 증상별 조치로 해결되면 끝낸다.
- 티켓: 두 번 이상 실패하거나 다시 시작 요구가 반복되면 엔드포인트지원팀이 원격으로 확인한다.


#### 처리 절차

1. 상태와 저장 공간·네트워크 연결을 확인한다.
2. IT-SW-001 3.7 표에 따라 조치를 안내한다.
3. 해결되지 않으면 원격 지원으로 소프트웨어 센터 에이전트 상태와 설치 로그를 확인하고 다시 설치한다.
4. 정상 설치를 확인하고 FIN 처리한다.

#### 처리 후 안내 문구

> 설치가 끝났습니다. 같은 증상이 다시 나오면 PC를 다시 시작한 뒤 [설치]를 눌러 주세요.

**재발 방지**

- 없음

**이관 시 전달 정보**

- 프로그램 이름
- 표시 상태
- 해 본 조치


## 4. 대형 장애 대응

- 같은 프로그램의 실행 오류·라이선스 만료 문의가 짧은 시간에 여러 부서에서 들어오면 개별 처리를 멈추고 대형 장애 후보로 보고 팀장에게 알린다 (MAN-00 공통 규칙 7).
- 대표 티켓 1건을 정하고 이후 같은 문의는 대표 티켓에 연결한다. 전사 공지와 ITssue 챗봇 첫 화면 안내를 요청한다.
- 라이선스 서버·계약 갱신 문제면 엔드포인트지원팀장이 구매 담당과 협의해 임시 사용 방법(공용 PC 등)을 정해 안내한다 (INQ-2026-00086).
- 복구 후 연결된 티켓을 한꺼번에 종료하고(해결 방법: "MI-YYYY-NN 대형 장애 복구로 일괄 해결") 장애 보고서에 원인·조치·재발 방지를 남긴다.

| --- | --- |
| 원인 | 확인된 원인 한 줄 |

| 재발 방지 | 같은 문의를 줄이기 위한 조치 (없으면 빈칸) |
| 관련 FAQ | 안내에 쓴 FAQ 번호 |
| 가이드 반영 | 임직원용 가이드에 추가·수정이 필요한지 (필요 / 불필요) |
