## 1. 개요

#### 목적

IT-SW-002로 들어오는 라이선스 문의(신청 승인·할당, 만료·재할당, 잔여 부족, 기기 정리·회수)를 같은 기준으로 처리한다.

#### 담당 범위

| 항목 | 내용 |
| --- | --- |
| 1차 처리 | 서비스데스크(L1): 로그인 계정·기간 확인 등 사용자 조치 안내 |
| 2차 이관 | 엔드포인트지원팀(L2): 할당·재할당·회수, 기기 등록 정리, 추가 구매 협의 |
| 배정 기준 | SW-02: SW 설치·라이선스 담당 (도진우, 현현정). 재배정은 엔드포인트지원팀장이 승인 |
| 관련 시스템 | 라이선스 관리 화면, 요청 현황, 구매 품의 |

## 2. 접수·분류 기준

임직원용 가이드의 항목별 기본값입니다. 긴급도 기준은 IT-STD-001 IT 서비스 운영 기준을 따릅니다.

| 번호 | 문의 유형 | 증상·요청 | 기본 긴급도 | 1차 처리 | 처리 방식 | 이관 대상 |
| --- | --- | --- | --- | --- | --- | --- |
| 3.1 | SW-02 | 라이선스 신청 승인·할당 | P4 | 엔드포인트지원팀 | 티켓 | 없음 |
| 3.2 | SW-02 | '라이선스가 만료되었습니다' 재할당 | P3 | 서비스데스크 | 티켓 | 엔드포인트지원팀 |
| 3.3 | SW-02 | 잔여 라이선스 부족 | P3 | 엔드포인트지원팀 | 티켓 | 없음 (구매는 팀장 협의) |
| 3.4 | SW-02 | 기기 수 초과·이전 PC 정리, 반납·회수 | P4 | 서비스데스크 | 즉시 처리 후 필요 시 티켓 | 엔드포인트지원팀 |

#### 처리 방식

- 즉시 처리: 안내만으로 끝낸 건. 티켓 없이 상담 기록만 남긴다.
- 티켓: 담당자 조치가 필요한 건. 담당 팀에 배정하고 상태를 RDY → IP → FIN → CLS 로 관리한다. FIN은 담당자 처리 완료, CLS는 문의자가 해결을 확인한 최종 종료다.

#### 긴급도 조정 조건

- SW-02는 기본 P3다. 신청 자체(업무 지장 없음)는 P4로 처리한다.
- "급합니다", 당일 마감처럼 업무가 막히면 P2로 올린다 (INQ-2026-00086).
- 같은 프로그램 만료가 여러 사람에게 동시에 나오면 계약 갱신 문제로 보고 4장 대형 장애 절차를 따른다.

## 3. 증상별 처리 절차

### 3.1 라이선스 신청 승인·할당

**문의 유형** SW-02 · **기본 긴급도** P4 · **1차 처리** 엔드포인트지원팀 · **처리 방식** 티켓 · **이관 대상** 없음

**접수 시 확인 질문**

- 요청서 번호와 프로그램·판은?
- 팀장 승인이 끝났나요?
- 사용 기간(종료일)은?

**판단 기준**

- 팀장 승인 전이면 할당하지 않는다.
- 잔여 좌석이 있으면 바로 할당한다. 없으면 3.3.
- 무료판으로 가능한 업무면 대체를 먼저 안내한다.


#### 처리 절차

1. 요청 현황에서 팀장 승인을 확인한다.
2. 라이선스 관리 화면에서 잔여 좌석을 확인한다.
3. 사용자 회사 계정에 할당하고 사용 기간·회수 예정일을 등록한다.
4. "할당 완료" 알림을 보내고 IT-SW-002 3.2 인증 방법을 안내한다.
5. FIN 처리한다.

#### 처리 목표

잔여 좌석이 있으면 접수 후 5영업일 안에 할당한다.

#### 처리 후 안내 문구

> 라이선스를 회사 계정에 할당했습니다. 소프트웨어 센터에서 설치한 뒤 회사 계정으로 로그인해 주세요 (IT-SW-002 3.2).

**재발 방지**

- 없음

**이관 시 전달 정보**

- 요청 번호
- 프로그램·판
- 사용 기간


### 3.2 '라이선스가 만료되었습니다' 재할당

**문의 유형** SW-02 · **기본 긴급도** P3 · **1차 처리** 서비스데스크 · **처리 방식** 티켓 · **이관 대상** 엔드포인트지원팀

**접수 시 확인 질문**

- 프로그램 이름과 판, 표시 메시지는?
- 회사 계정으로 로그인했나요?
- 신청한 사용 기간이 남아 있나요?

**판단 기준**

- 즉시 처리: 개인 계정 로그인·기간 종료처럼 사용자 조치로 끝나면 IT-SW-002 3.3·3.4·3.7을 안내한다.
- 티켓: 기간이 남았는데 만료로 나오면 갱신 누락으로 보고 재할당한다 (INQ-2026-00087, 00227, 00308).
- 잔여 좌석이 없어 재할당할 수 없으면 3.3.


#### 처리 절차

1. 라이선스 관리 화면에서 사용자 할당 상태와 계약 갱신 내역을 확인한다.
2. 갱신 누락이면 다시 할당한다.
3. 사용자에게 다시 로그인하도록 안내하고 정상 실행을 확인한다.
4. FIN 처리한다.

#### 처리 후 안내 문구

> 라이선스를 다시 할당했습니다. 프로그램에서 로그아웃한 뒤 회사 계정으로 다시 로그인해 주세요.

**재발 방지**

- 연간 계약 갱신 때 할당 목록 일괄 점검

**이관 시 전달 정보**

- 프로그램·판
- 표시 메시지
- 할당 상태


### 3.3 잔여 라이선스 부족

**문의 유형** SW-02 · **기본 긴급도** P3 · **1차 처리** 엔드포인트지원팀 · **처리 방식** 티켓 · **이관 대상** 없음 (구매는 팀장 협의)

**접수 시 확인 질문**

- 언제까지 필요한가요?
- 업무가 막혔나요? 대체할 방법이 있나요?
- 팀 비용 구매가 가능한가요?

**판단 기준**

- 급하지 않으면 반납 대기 순서에 넣는다.
- 업무가 막혀 급하면 P2로 올리고 임시 사용 방법을 함께 안내한다 (INQ-2026-00086).
- 구매는 팀장 협의와 결재 후 진행한다.


#### 처리 절차

1. 장기 미사용(90일 이상) 라이선스가 있는지 확인하고 회수 안내를 보낸다.
2. 반납 대기 또는 팀 비용 구매 중 사용자와 정한다.
3. 구매가 필요하면 구매 품의를 올리고 상태를 IP로 둔다.
4. 임시로 공용 PC 등 쓸 수 있는 방법을 안내한다.
5. 할당이 끝나면 알리고 FIN 처리한다.

#### 처리 후 안내 문구

> 남은 라이선스가 없어 추가 구매를 진행하고 있습니다. 그동안은 안내드린 방법으로 업무를 진행해 주세요. 할당되면 바로 알려 드리겠습니다.

**재발 방지**

- 없음

**이관 시 전달 정보**

- 요청 번호
- 필요 시점과 업무 영향
- 구매 진행 상태


### 3.4 기기 수 초과·이전 PC 정리, 반납·회수

**문의 유형** SW-02 · **기본 긴급도** P4 · **1차 처리** 서비스데스크 · **처리 방식** 즉시 처리 후 필요 시 티켓 · **이관 대상** 엔드포인트지원팀

**접수 시 확인 질문**

- 이전 PC를 반납했나요?
- 부서 이동·퇴사·PC 교체 중 어떤 상황인가요?

**판단 기준**

- 즉시 처리: [다른 기기에서 로그아웃]으로 해결되면 끝낸다.
- 티켓: 반납한 PC에 등록이 남았으면 기기 등록을 정리한다.
- 퇴사자 라이선스는 퇴사일 18시 계정 비활성화와 함께 회수해 다른 직원에게 재할당한다 (FAQ-035).


#### 처리 절차

1. 라이선스 관리 화면에서 등록 기기 목록을 확인한다.
2. 반납한 기기의 등록을 지운다.
3. 퇴사·반납 건은 회수하고 대기자에게 재할당한다.
4. FIN 처리한다.

#### 처리 후 안내 문구

> 이전 PC의 기기 등록을 정리했습니다. 새 PC에서 다시 로그인해 주세요.

**재발 방지**

- 없음

**이관 시 전달 정보**

- 프로그램
- 이전 PC 자산 번호
- 상황(이동·퇴사·교체)


## 4. 대형 장애 대응

- 같은 프로그램의 실행 오류·라이선스 만료 문의가 짧은 시간에 여러 부서에서 들어오면 개별 처리를 멈추고 대형 장애 후보로 보고 팀장에게 알린다 (MAN-00 공통 규칙 7).
- 대표 티켓 1건을 정하고 이후 같은 문의는 대표 티켓에 연결한다. 전사 공지와 ITssue 챗봇 첫 화면 안내를 요청한다.
- 라이선스 서버·계약 갱신 문제면 엔드포인트지원팀장이 구매 담당과 협의해 임시 사용 방법(공용 PC 등)을 정해 안내한다 (INQ-2026-00086).
- 복구 후 연결된 티켓을 한꺼번에 종료하고(해결 방법: "MI-YYYY-NN 대형 장애 복구로 일괄 해결") 장애 보고서에 원인·조치·재발 방지를 남긴다.

| 항목 | 적는 내용 |
| --- | --- |
| 원인 | 확인된 원인 한 줄 |
| 조치 내용 | 실제로 한 조치. 안내만으로 끝낸 건은 앞에 [즉시 처리] |
| 재발 방지 | 같은 문의를 줄이기 위한 조치 (없으면 빈칸) |
| 관련 FAQ | 안내에 쓴 FAQ 번호 |
| 가이드 반영 | 임직원용 가이드에 추가·수정이 필요한지 (필요 / 불필요) |
