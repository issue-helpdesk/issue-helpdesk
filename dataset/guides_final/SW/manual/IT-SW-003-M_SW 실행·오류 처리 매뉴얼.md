## 1. 개요

#### 목적

IT-SW-003으로 들어오는 실행·오류 문의(Office, 보호된 보기, 앱 로그인 창, 비밀번호 관리자, 개발도구 인증서, 메일 프로그램)를 같은 기준으로 처리한다.

#### 담당 범위

| 항목 | 내용 |
| --- | --- |
| 1차 처리 | 서비스데스크(L1): 기본 조치·안전 모드·차단 해제·비밀번호 관리자·인증서 등록 안내 |
| 2차 이관 | 엔드포인트지원팀(L2): 64비트 Office 재설치, 인증서 저장소 점검, 메일 프로그램 색인·프로필 재생성 |
| 배정 기준 | SW-03·SW-04: 프린터·오피스 1차 (박서연, 서승현) / SW-05: SW 설치·라이선스 (도진우, 현현정) / SW-06: 메일 프로그램 (이예서). 재배정은 각 팀장이 승인 |
| 관련 시스템 | 원격 지원 도구, 소프트웨어 센터 관리 화면, 상담 기록 시스템 |

## 2. 접수·분류 기준

임직원용 가이드의 항목별 기본값입니다. 긴급도 기준은 IT-STD-001 IT 서비스 운영 기준을 따릅니다.

| 번호 | 문의 유형 | 증상·요청 | 기본 긴급도 | 1차 처리 | 처리 방식 | 이관 대상 |
| --- | --- | --- | --- | --- | --- | --- |
| 3.1 | SW-03 | Office '응답 없음'·추가 기능 충돌 | P3 | 서비스데스크 | 즉시 처리 후 필요 시 티켓 | 엔드포인트지원팀 |
| 3.2 | SW-03 | 보호된 보기·앱 로그인 창 멈춤 | P3 | 서비스데스크 | 즉시 처리 | 없음 |
| 3.3 | SW-04 | 비밀번호 관리자 | P4 | 서비스데스크 | 즉시 처리 | 없음 |
| 3.4 | SW-05 | 개발도구 SSL 인증서 오류 | P3 | 서비스데스크 | 즉시 처리 후 필요 시 티켓 | 엔드포인트지원팀 |
| 3.5 | SW-06 | 메일 프로그램 느림·'프로필을 로드하는 중' 멈춤 | P3 | 엔드포인트지원팀 | 티켓 | 없음 |

#### 처리 방식

- 즉시 처리: 안내만으로 끝낸 건. 티켓 없이 상담 기록만 남긴다.
- 티켓: 담당자 조치가 필요한 건. 담당 팀에 배정하고 상태를 RDY → IP → FIN → CLS 로 관리한다. FIN은 담당자 처리 완료, CLS는 문의자가 해결을 확인한 최종 종료다.

#### 긴급도 조정 조건

- SW-03·SW-05·SW-06은 기본 P3, SW-04는 P4다.
- "급합니다", 오늘 고객 미팅·마감이 있으면 한 단계 올린다 (INQ-2026-00007, 00175, 00184, 00296, 00336).
- 여러 부서에서 같은 프로그램이 동시에 안 되면 4장 대형 장애 절차를 따른다.

## 3. 증상별 처리 절차

### 3.1 Office '응답 없음'·추가 기능 충돌

**문의 유형** SW-03 · **기본 긴급도** P3 · **1차 처리** 서비스데스크 · **처리 방식** 즉시 처리 후 필요 시 티켓 · **이관 대상** 엔드포인트지원팀

**접수 시 확인 질문**

- 어떤 파일에서 생기나요? 다른 파일도 같은가요?
- 안전 모드로 열어 봤나요?
- 최근 설치한 추가 기능이 있나요?

**판단 기준**

- 즉시 처리: 안전 모드 정상 → 추가 기능 해제 안내로 끝낸다 (INQ-2026-00028, 00159, 00169).
- 티켓: 추가 기능을 꺼도 큰 파일에서 계속 멈추면 메모리 부족으로 보고 64비트 Office 재설치를 진행한다 (INQ-2026-00353).


#### 처리 절차

1. IT-SW-003 3.2 순서로 안전 모드와 추가 기능 해제를 안내한다.
2. 해결되지 않으면 원격 지원으로 Office 비트 수와 메모리 사용량을 확인한다.
3. 32비트면 64비트 Office로 다시 설치한다.
4. 정상 동작을 확인하고 FIN 처리한다.

#### 처리 후 안내 문구

> 충돌하던 추가 기능을 꺼서 정상으로 열립니다. 같은 증상이 다시 나면 안전 모드로 먼저 열어 보세요.

**재발 방지**

- 없음

**이관 시 전달 정보**

- 파일 크기
- 추가 기능 목록
- Office 버전·비트 수


### 3.2 보호된 보기·앱 로그인 창 멈춤

**문의 유형** SW-03 · **기본 긴급도** P3 · **1차 처리** 서비스데스크 · **처리 방식** 즉시 처리 · **이관 대상** 없음

**접수 시 확인 질문**

- 파일을 어디서 받았나요? 보낸 사람을 아나요?
- 로그인 창은 어떤 프로그램인가요? [브라우저로 로그인]이 보이나요?

**판단 기준**

- 즉시 처리: 보호된 보기는 출처 확인 후 [차단 해제]를 안내한다 (INQ-2026-00184, 00226, 00234).
- 즉시 처리: 앱 로그인 창 멈춤은 앱 캐시 삭제·재로그인, 필요하면 웹 브라우저 로그인으로 우회하도록 안내한다 (INQ-2026-00059, 00132, 00336).
- 전환: 출처가 의심스러우면 해제하지 말고 SEC-01로 분류한다.


#### 처리 절차

1. IT-SW-003 3.3 또는 3.4를 안내한다.
2. 해결을 확인하고 상담 기록을 남긴다.

#### 처리 후 안내 문구

> 파일 속성에서 차단을 해제해 편집할 수 있습니다. 출처가 확실한 파일에만 해 주세요.

**재발 방지**

- 없음

**이관 시 전달 정보**

- 파일 이름·받은 경로
- 프로그램 이름


### 3.3 비밀번호 관리자

**문의 유형** SW-04 · **기본 긴급도** P4 · **1차 처리** 서비스데스크 · **처리 방식** 즉시 처리 · **이관 대상** 없음

**접수 시 확인 질문**

- 어느 사이트에서 자동 입력이 안 되나요?
- 브라우저 비밀번호를 옮기려는 건가요?

**판단 기준**

- 즉시 처리: 사이트 로그인 화면 변경이면 URL 재등록을 안내한다 (INQ-2026-00217, 00276).
- 비밀번호 값은 묻지도 받지도 않는다.


#### 처리 절차

1. IT-SW-003 3.5를 안내한다.
2. CSV로 옮겼다면 파일을 바로 지웠는지 확인한다.
3. 상담 기록을 남긴다.

#### 처리 후 안내 문구

> 해당 항목의 사이트 주소를 다시 등록하면 자동 입력이 됩니다. 옮길 때 만든 CSV 파일은 바로 지워 주세요.

**재발 방지**

- 없음

**이관 시 전달 정보**

- 사이트 주소


### 3.4 개발도구 SSL 인증서 오류

**문의 유형** SW-05 · **기본 긴급도** P3 · **1차 처리** 서비스데스크 · **처리 방식** 즉시 처리 후 필요 시 티켓 · **이관 대상** 엔드포인트지원팀

**접수 시 확인 질문**

- 어떤 도구에서 나나요? (pip·npm·git 등)
- 사내 루트 인증서를 설치했나요?
- 집에서는 되나요?

**판단 기준**

- 즉시 처리: 사내 루트 인증서 설치와 도구별 등록 안내로 해결되면 끝낸다 (INQ-2026-00007, 00154, 00201, 00296).
- 티켓: 등록 후에도 같으면 엔드포인트지원팀이 원격으로 인증서 저장소와 환경 변수를 확인한다.
- SSL 검증을 끄는 방법은 안내하지 않는다 (MAN-00 공통 규칙 2).


#### 처리 절차

1. IT-SW-003 3.6을 안내한다.
2. 해결되지 않으면 원격 지원으로 인증서 파일 위치와 환경 변수·git 설정을 확인한다.
3. 정상 동작을 확인하고 FIN 처리한다.

#### 처리 후 안내 문구

> 사내 루트 인증서를 개발 도구에 등록해 정상으로 연결됩니다. 새 PC에서도 같은 등록이 필요합니다.

**재발 방지**

- 개발자 온보딩 가이드에 사내 인증서 등록 절차 포함 (문의이력)

**이관 시 전달 정보**

- 도구와 실행 명령
- 오류 전문
- 인증서 설치 여부


### 3.5 메일 프로그램 느림·'프로필을 로드하는 중' 멈춤

**문의 유형** SW-06 · **기본 긴급도** P3 · **1차 처리** 엔드포인트지원팀 · **처리 방식** 티켓 · **이관 대상** 없음

**접수 시 확인 질문**

- 검색이 안 되고 느린가요, 실행이 멈추나요?
- 웹 메일(그룹웨어 [메일])은 정상인가요?
- 다른 사람도 같은가요?

**판단 기준**

- 웹 메일이 정상이면 PC 메일 프로그램 문제로 보고 엔드포인트지원팀(메일 프로그램 담당)이 처리한다.
- 검색만 안 되고 느리면 검색 색인 손상 (INQ-2026-00043, 00064, 00301).
- "프로필을 로드하는 중"에서 멈추면 메일 프로필 손상 (INQ-2026-00089, 00157, 00175).
- 웹 메일도 안 되거나 여러 명이면 SYS-06·SYS-09로 전환한다 (IT-SYS-004-M, IT-SYS-003-M).


#### 처리 절차

1. 급한 업무는 웹 메일로 하도록 안내한다.
2. 원격 지원으로 접속해 메일 프로그램을 종료한다.
3. 검색 색인 손상이면 색인을 다시 만든다.
4. 프로필 손상이면 새 메일 프로필을 만들고 계정을 다시 연결한다.
5. 검색·실행이 정상인지 사용자와 확인하고 FIN 처리한다.

#### 처리 후 안내 문구

> 메일 프로그램의 검색 색인(또는 메일 프로필)을 다시 만들어 정상으로 동작합니다. 색인을 다시 만드는 동안은 검색 결과가 일부만 나올 수 있습니다.

**재발 방지**

- 없음

**이관 시 전달 정보**

- 메일 프로그램 이름·버전
- 증상(검색 느림·프로필 멈춤)
- 웹 메일 정상 여부


## 4. 대형 장애 대응

- 같은 프로그램의 실행 오류·라이선스 만료 문의가 짧은 시간에 여러 부서에서 들어오면 개별 처리를 멈추고 대형 장애 후보로 보고 팀장에게 알린다 (MAN-00 공통 규칙 7).
- 대표 티켓 1건을 정하고 이후 같은 문의는 대표 티켓에 연결한다. 전사 공지와 ITssue 챗봇 첫 화면 안내를 요청한다.
- 라이선스 서버·계약 갱신 문제면 엔드포인트지원팀장이 구매 담당과 협의해 임시 사용 방법(공용 PC 등)을 정해 안내한다 (INQ-2026-00086).
- 복구 후 연결된 티켓을 한꺼번에 종료하고(해결 방법: "MI-YYYY-NN 대형 장애 복구로 일괄 해결") 장애 보고서에 원인·조치·재발 방지를 남긴다.

| 항목 | 적는 내용 |
| --- | --- |
| 원인 | 확인된 원인 한 줄 |
| 조치 내용 | 실제로 한 조치. 안내만으로 끝낸 건은 앞에 [즉시 처리] |
| 재발 방지 | 같은 문의를 줄이기 위한 조치 (없으면 빈칸) |
| 관련 FAQ | 안내에 쓴 FAQ 번호 |
| 가이드 반영 | 임직원용 가이드에 추가·수정이 필요한지 (필요 / 불필요) |
