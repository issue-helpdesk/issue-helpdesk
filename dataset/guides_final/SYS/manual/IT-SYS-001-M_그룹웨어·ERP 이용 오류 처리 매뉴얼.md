## 1. 개요

#### 목적

전자결재 오류(SYS-01)와 개인 단위 ERP 오류(SYS-02) 문의를 접수·판단·처리하는 내부 절차를 정한다. 사용자 안내는 IT-SYS-001을 기준으로 한다.

#### 담당 범위

| 항목 | 내용 |
| --- | --- |
| 1차 처리 | 서비스데스크(L1): 첨부파일명·브라우저 캐시 안내, 마감 여부 확인 후 업무시스템팀 배정 |
| 2차 이관 | 업무시스템팀(L2): 조직도 수동 동기화, 회계기간 임시 오픈(재무팀 확인), ERP 권한 재매핑 |
| 배정 기준 | 업무시스템팀 L2 · ERP 영역 (SYS-02) |
| 배정 기준 | 업무시스템팀 L2 · 전자결재·권한 영역 (SYS-01) |
| 관련 시스템 | 그룹웨어 관리 콘솔, 조직도 동기화 화면, ERP 관리 화면 |

## 2. 접수·분류 기준

사용자 가이드의 블록별 기본값이다. 긴급도 기준은 IT-STD-001 IT 서비스 운영 기준을 따른다.

| 번호 | 문의 유형 | 증상·요청 | 기본 긴급도 | 1차 처리 | 처리 방식 | 이관 대상 |
| --- | --- | --- | --- | --- | --- | --- |
| 3.1 | SYS-01 | 전자결재 상신 오류 | P2 | 업무시스템팀 | 티켓 | 없음 |
| 3.2 | SYS-01 | 결재선 이전 부서 표시 | P2 | 업무시스템팀 | 티켓 | 없음 |
| 3.3 | SYS-02 | 회계기간 마감 전표 저장 불가 | P2 | 업무시스템팀 | 티켓 | 없음 |
| 3.4 | SYS-02 | ERP 조회 화면 흰 화면 | P2 | 업무시스템팀 | 티켓 | 없음 |
| 3.5 | SYS-02 | 업데이트 후 ERP 지급 처리 불가 | P2 | 업무시스템팀 | 티켓 | 없음 |

#### 처리 방식

- 즉시 처리: 서비스데스크(L1)가 안내만으로 끝낸 건. 티켓 없이 상담 기록만 남긴다.
- 티켓: 담당자 조치가 필요한 건. 담당팀에 배정하고 상태를 RDY → WIP → FIN → CLS 으로 관리한다.

#### 긴급도 조정 조건

- 마감 당일 건은 P2를 유지하고 당일 처리한다.
- 같은 ERP 오류가 여러 부서에서 동시에 접수되면 SYS-03(P1)으로 전환하고 IT-SYS-003-M을 따른다.
- ERP가 느리기만 하면 IT-SYS-002-M으로 분류한다.

## 3. 증상별 처리 절차

### 3.1 전자결재 상신 시 '처리 중 오류가 발생했습니다'가 뜸

**문의 유형** SYS-01 · **기본 긴급도** P2 · **1차 처리** 업무시스템팀 · **이관 대상** 없음

**접수 시 확인 질문**

- 첨부파일 이름에 특수문자가 있나요?
- 오늘 마감 건인가요?
- 화면 메시지는 무엇인가요?

**판단 기준**

- 첨부파일명 특수문자면 파일명 변경 안내로 해결하고 티켓을 바로 완료한다.
- 파일명을 바꿔도 오류가 나면 업무시스템팀이 서버 로그를 확인한다.


#### 처리 절차

1. 그룹웨어 관리 콘솔에서 상신 오류 로그를 확인한다.
2. 첨부 업로드 실패면 파일명 변경 후 재상신을 안내한다.
3. 정상 상신을 확인한다.

#### 처리 후 안내 문구

> 첨부파일 이름의 특수문자를 지우고 다시 상신해 주세요. 정상 처리된 것을 확인했습니다.

**재발 방지**

- 첨부파일명 특수문자 자동 치환 기능 요청

**이관 시 전달 정보**

- 없음 (업무시스템팀에서 종결)


### 3.2 결재선에 부서를 옮긴 사람이 이전 부서로 표시됨

**문의 유형** SYS-01 · **기본 긴급도** P2 · **1차 처리** 업무시스템팀 · **이관 대상** 없음

**접수 시 확인 질문**

- 결재선 대상자는 누구이며 발령일은 언제인가요?
- 오늘 처리해야 하나요?

**판단 기준**

- 당일 처리가 필요하면 티켓으로 조직도를 수동 동기화한다.
- 급하지 않으면 다음 날 오전 6시 자동 동기화를 안내한다.


#### 처리 절차

1. 인사 발령 정보를 확인한다.
2. 조직도를 수동으로 동기화한다.
3. 결재선에 새 부서가 표시되는지 확인한다.

#### 처리 후 안내 문구

> 조직도를 동기화했습니다. 결재선을 다시 지정해 상신해 주세요.

**재발 방지**

- 첨부파일명 특수문자 자동 치환 기능 요청

**이관 시 전달 정보**

- 없음 (업무시스템팀에서 종결)


### 3.3 ERP 전표 저장 시 '회계기간이 마감되었습니다'가 뜸

**문의 유형** SYS-02 · **기본 긴급도** P2 · **1차 처리** 업무시스템팀 · **이관 대상** 없음

**접수 시 확인 질문**

- 전표 날짜와 회계기간은 언제인가요?
- 재무팀과 협의했나요?

**판단 기준**

- 전표 날짜 오류면 수정 안내로 끝낸다.
- 마감 기간 저장이 필요하면 재무팀 확인 후 티켓으로 해당 기간을 임시 오픈한다.


#### 처리 절차

1. 재무팀에 기간 오픈 여부를 확인한다.
2. 승인되면 해당 회계기간을 임시로 연다.
3. 전표 저장을 확인하고 기간을 다시 닫는다.

#### 처리 후 안내 문구

> 재무팀 확인 후 해당 회계기간을 임시로 열었습니다. 전표를 저장한 뒤 알려 주세요.

**재발 방지**

- 없음

**이관 시 전달 정보**

- 없음 (업무시스템팀에서 종결)


### 3.4 ERP 거래처 조회 화면이 하얗게만 나옴

**문의 유형** SYS-02 · **기본 긴급도** P2 · **1차 처리** 업무시스템팀 · **이관 대상** 없음

**접수 시 확인 질문**

- 어떤 메뉴인가요?
- 브라우저 캐시를 지워 봤나요?

**판단 기준**

- 캐시 삭제 안내로 해결되면 티켓을 바로 완료한다.
- 여러 명이 같은 메뉴에서 같으면 화면 배포 문제로 보고 업무시스템팀이 확인한다.


#### 처리 절차

1. 브라우저 캐시 삭제를 안내한다.
2. 메뉴가 정상으로 열리는지 확인한다.

#### 처리 후 안내 문구

> 브라우저 캐시를 지운 뒤 화면이 정상으로 열리는 것을 확인했습니다.

**재발 방지**

**이관 시 전달 정보**

### 3.5 업데이트 이후 ERP 대금 지급 처리가 안 됨

**문의 유형** SYS-02 · **기본 긴급도** P2 · **1차 처리** 업무시스템팀 · **이관 대상** 없음

**접수 시 확인 질문**

- 언제부터 안 되나요? (업데이트 이후인가요?)
- 같은 팀 다른 사람도 같은가요?

**판단 기준**

- 업데이트 이후 권한 문제로 보고 티켓으로 처리한다.
- 여러 부서에서 같으면 업데이트 배포 문제로 묶어 처리한다.


#### 처리 절차

1. ERP 관리 화면에서 지급 모듈 권한 매핑을 확인한다.
2. 누락된 권한을 다시 매핑한다.
3. 지급 처리를 확인한다.

#### 처리 후 안내 문구

> 지급 기능 권한을 다시 연결했습니다. 대금 지급을 다시 처리해 주세요.

**재발 방지**

- 없음

## 4. 대형 장애 대응

1. ERP가 여러 부서에서 동시에 열리지 않거나 저장되지 않으면 SYS-03 대형 장애로 판단하고 IT-SYS-003-M을 따른다.
2. 대표 티켓(MI-YYYY-NN)을 만들고, 같은 증상의 개별 문의는 대표 티켓에 연결한다.
3. 그룹웨어 공지사항에 장애 공지를 올리고 30분마다 갱신한다.
4. 복구 후 개별 문의를 대표 티켓 기준으로 일괄 완료(FIN) 처리하고, IT운영·보안 조직장에게 원인을 보고한다.
