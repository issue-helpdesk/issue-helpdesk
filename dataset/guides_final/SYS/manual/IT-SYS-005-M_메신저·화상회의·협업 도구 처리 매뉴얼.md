## 1. 개요

#### 목적

메신저·화상회의(SYS-10), 공유 캘린더·그룹 메일(SYS-11), 협업 채널 관리(SYS-12) 문의를 접수·처리하는 내부 절차를 정한다. 사용자 안내는 IT-SYS-005를 기준으로 한다.

#### 담당 범위

| 항목 | 내용 |
| --- | --- |
| 1차 처리 | 서비스데스크(L1): 회의 앱 권한·장치·알림 설정 안내, 회의 앱 재설치, 그룹 메일·캘린더 권한·게스트 초대 처리 |
| 2차 이관 | 없음 (서비스데스크에서 종결) |
| 배정 기준 | 서비스데스크 L1 · 메일·협업 1차 영역 (SYS-10, SYS-11, SYS-12) |
| 관련 시스템 | 메신저 관리 콘솔, 그룹웨어 관리 콘솔(그룹 메일·캘린더), 원격 지원 도구 |

## 2. 접수·분류 기준

사용자 가이드의 블록별 기본값이다. 긴급도 기준은 IT-STD-001 IT 서비스 운영 기준을 따른다.

| 번호 | 문의 유형 | 증상·요청 | 기본 긴급도 | 1차 처리 | 처리 방식 | 이관 대상 |
| --- | --- | --- | --- | --- | --- | --- |
| 3.1 | SYS-10 | 회의 마이크 소리 안 감 | P3 | 서비스데스크 | 티켓 | 없음 |
| 3.2 | SYS-10 | 카메라 사용 중인 장치 | P3 | 서비스데스크 | 즉시 처리 후 필요 시 티켓 | 없음 |
| 3.3 | SYS-10 | 메신저 알림 안 뜸 | P3 | 서비스데스크 | 즉시 처리 후 필요 시 티켓 | 없음 |
| 3.4 | SYS-10 | 회의 소리 지연 | P3 | 서비스데스크 | 티켓 | 없음 |
| 3.5 | SYS-10 | 회의 화면 멈춤·끊김 | P3 | 서비스데스크 | 즉시 처리 | 없음 |
| 3.6 | SYS-10 | 업데이트 후 회의 앱 종료 | P3 | 서비스데스크 | 티켓 | 없음 |
| 3.7 | SYS-11 | 그룹 메일 생성·멤버 추가 | P4 | 서비스데스크 | 티켓 | 없음 |
| 3.8 | SYS-11 | 그룹 메일 외부 수신 허용 | P4 | 서비스데스크 | 티켓 | 없음 |
| 3.9 | SYS-11 | 공유 캘린더 편집 권한 | P4 | 서비스데스크 | 티켓 | 없음 |
| 3.10 | SYS-12 | 외부 게스트 초대 | P4 | 서비스데스크 | 티켓 | 없음 |
| 3.11 | SYS-12 | 게스트 비공개 채널 미표시 | P4 | 서비스데스크 | 티켓 | 없음 |

#### 처리 방식

- 즉시 처리: 서비스데스크(L1)가 안내만으로 끝낸 건. 티켓 없이 상담 기록만 남긴다.
- 티켓: 담당자 조치가 필요한 건. 담당팀에 배정하고 상태를 RDY → IP → FIN → CLS 으로 관리한다.

#### 긴급도 조정 조건

- 고객사 회의 등 당일 업무 차질을 말하면 SYS-10을 P2로 올린다.
- 마감 일정이 걸린 그룹 메일·게스트 요청은 P4를 P3로 올린다.
- 여러 부서에서 동시에 메신저·화상회의에 접속하지 못하면 대표 티켓으로 묶는다.

## 3. 증상별 처리 절차

### 3.1 화상회의에서 내 목소리가 상대방에게 들리지 않음

**문의 유형** SYS-10 · **기본 긴급도** P3 · **1차 처리** 서비스데스크 · **이관 대상** 없음

**접수 시 확인 질문**

- 회의 앱에서 마이크가 켜져 있나요?
- OS 마이크 권한이 허용되어 있나요?

**판단 기준**

- 마이크 권한 허용 안내로 해결되면 티켓을 바로 완료한다.


#### 처리 절차

1. OS 마이크 권한과 회의 앱 장치 선택을 확인한다.
2. 테스트 통화로 확인한다.

#### 처리 후 안내 문구

> 회의 앱의 마이크 권한을 허용했습니다. 장치 테스트로 소리를 확인해 주세요.

**재발 방지**

- 없음

**이관 시 전달 정보**

- 없음 (서비스데스크에서 종결)


### 3.2 화상회의 카메라가 '사용 중인 장치'라며 켜지지 않음

**접수 시 확인 질문**

- 메신저 통화 등 다른 앱이 켜져 있나요?

**판단 기준**

- 카메라를 쓰는 앱 종료 안내로 즉시 처리한다.

2. 카메라 권한을 확인한다.

#### 처리 후 안내 문구

> 카메라를 쓰던 다른 앱을 종료했습니다. 회의 앱에서 카메라를 다시 켜 주세요.

### 3.10 메신저 채널에 외부 협력사 게스트 초대 신청

**문의 유형** SYS-12 · **기본 긴급도** P4 · **1차 처리** 서비스데스크 · **이관 대상** 없음

**접수 시 확인 질문**

- 채널 이름과 게스트 이메일은 무엇인가요?
- 팀장 승인을 받았나요?
- 초대 기간은 언제까지인가요?

**판단 기준**

- 팀장 승인이 확인되면 티켓으로 초대한다.
- 승인이 없으면 게스트 초대 신청 경로를 안내한다.


#### 처리 절차

1. 승인을 확인한다.
2. 게스트 계정을 만들고 채널에 초대한다.
3. 기간이 끝나면 게스트를 해제하도록 일정을 등록한다.

## 4. 대형 장애 대응

1. 여러 부서에서 동시에 메신저나 화상회의에 접속하지 못하면 대형 장애로 판단한다. 통합 로그인 장애면 IT-ACC-001-M, 네트워크 장애면 IT-NET-003-M을 함께 따른다.
2. 대표 티켓(MI-YYYY-NN)을 만들고, 같은 증상의 개별 문의는 대표 티켓에 연결한다.
3. 그룹웨어 공지사항에 장애 공지를 올리고 30분마다 갱신한다.
4. 복구 후 개별 문의를 대표 티켓 기준으로 일괄 완료(FIN) 처리하고, IT운영·보안 조직장에게 원인을 보고한다.
