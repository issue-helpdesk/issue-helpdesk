02. 승인 및 처리 결과 확인

신청번호는 보관하고, 같은 요청을 새로 접수하기 전에 기존 상태를 확인하세요.

1

권한 설정 완료 확인

신청 승인이 끝났더라도 담당자의 권한 반영이 남

아 있을 수 있습니다. 처리 완료 안내를 확인합니

다.

2

본인 계정으로 확인

설정 완료 안내를 받으면 신청한 메뉴나 폴더를

사용해 봅니다. 신청하지 않은 자료까지 보이면

담당자에게 알려 주세요.

신청 접수, 권한 승인, 담당자의 권한 설정, 실제 사용 확인은 각각 별도로 확인해야 합니다.

05. 자주 묻는 질문 및 주의사항

권한이 보인다는 사실과 사용 승인은 같지 않습니다.

승인만 받으면 바로 쓸 수 있나요?

담당자의 실제 반영과 자원별 추가 승인 필요 여부를 확인해야 합니다.

동료와 같은 권한을 달라고 해도 되나요?

동료 권한 전체 복제 대신 내 업무에 필요한 기능을 적습니다.

임시·다른 부서·관리자 권한은요?

사유·범위·기간과 승인 경로를 확인합니다. PC 관리자 권한이 필요한 설치는 설치 담당자에게 요청합니

다.

이동 후 새 부서 폴더가 안 보여요.

발령일·기존 신청번호·대상 자원을 전달합니다. 별도 부서이동 가이드에서 반영과 회수를 확인합니다.

공유하거나 우회하지 마세요

• 계정 대여·비밀번호·인증번호 공유 금지

• API 키·복구코드·업무 기밀을 캡처에 넣지 않기

• 보안 설정 해제·권한 임의 변경 금지

• 보이면 안 되는 자료는 추가 열람·다운로드 중단 후 신

고
