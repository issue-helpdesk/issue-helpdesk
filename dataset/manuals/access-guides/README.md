## 등록·운영 기준
- PDF와 MD는 같은 문서의 표현 형식입니다. RAG 등록 시 한 형식만 선택하여 중복 검색을 방지합니다.
- 임직원용은 사내 일반, 담당자용은 지정 담당 그룹·운영 관리자 열람으로 구분합니다. 폴더·표지 표시만으로 접근이 제한되지는 않습니다.
- AI 운영 기준은 시스템 프롬프트·서비스 정책 관리용입니다. 일반 사용자 답변용 Knowledge에 혼합 등록하지 않습니다.
- 검색 ACL, 외부 전송 허용 여부, 문서 버전·활성 여부는 백엔드에서 별도 적용합니다. 외부 전송이 미확인인 문서는 허용으로 간주하지 않습니다.
- 기존 MAN 문서는 수정·삭제하지 않았습니다. 정식 등록 전 담당자가 주제·정책 중복을 확인하고 현행 문서를 선정해야 합니다.
- 이전 IT-ACS-001 v0.8 PDF는 Git 이력에 남기고 현재 폴더에서는 v0.9로 교체합니다. 다른 구버전도 RAG에 함께 활성화하지 않습니다.
