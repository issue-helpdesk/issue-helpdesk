## 1. 프로젝트 개요

**ITssue HelpDesk**는 사내에서 반복적으로 발생하는 IT 문의를 AI Agent가 이해하고, 사내 Guide를 기반으로 1차 대응하는 서비스이다.

단순히 질문에 답변하는 챗봇에 그치지 않고, AI만으로 해결하기 어려운 문제나 실제 담당자의 조치가 필요한 요청은 **사용자의 확인을 거쳐 Jira Ticket으로 연결**한다.

이후 담당자의 처리 과정과 결과까지 사용자에게 연결하여,

> **문의 → AI 안내 → 필요 시 담당자 연결 → 실제 처리 → 결과 확인**
> 

까지 하나의 HelpDesk Flow로 관리하는 것을 목표로 한다.

## 2. 기획 배경 및 문제 정의

기업 내부에서는 계정·로그인, 접근권한, VPN·네트워크, Software·라이선스, Hardware·업무 PC, 사내 시스템, 정보보안 등 다양한 IT 문의가 반복적으로 발생한다.

간단한 문제라도 사용자는 관련 Guide나 담당자를 직접 찾아야 하고, IT 담당자는 반복적인 문의에 지속적으로 대응해야 한다.

또한 AI가 해결 방법을 안내하더라도 실제 권한 변경이나 시스템 조치가 필요한 경우, 사용자는 다시 별도의 HelpDesk나 Ticket 시스템을 찾아 요청해야 하는 경우가 많다.

### Problem

**① 반복적인 IT 문의**

유사한 문의가 반복적으로 발생하면서 IT 담당자의 대응 리소스가 소모된다.

**② 정보 탐색의 어려움**

사용자는 문제가 발생했을 때 적절한 사내 Guide나 담당자를 직접 찾아야 한다.

**③ AI 안내와 실제 업무의 단절**

AI가 해결 방법을 안내할 수는 있지만 실제 조치가 필요한 문제는 다시 담당자나 별도의 업무 시스템으로 연결해야 한다.

**④ 해결 경험의 재사용 부족**

담당자가 문제를 해결하더라도 해당 경험이 조직의 Guide로 축적되지 않으면 유사한 문의가 반복된다.

#### **⑤ 문의 이력의 분산과 추적 어려움**

IT 문의가 메신저, 메일, 전화, 구두 등 다양한 경로로 접수되면서 문의 내용과 처리 과정이 일관되게 기록되지 않는다.

이로 인해 문의의 진행 상태나 처리 결과를 추적하기 어렵고, 이전 문의 및 해결 이력을 다시 활용하기도 어렵다.

> ITssue는 분산된 IT 문의를 하나의 Flow로 연결하고, 문의의 접수·안내·실제 처리·결과 확인 과정 사이의 단절을 줄이는 것에서 시작한다.

## 3. 서비스 목표

ITssue는 **모든 IT 업무를 AI가 자동으로 처리하는 서비스**를 목표로 하지 않는다.

AI가 해결할 수 있는 반복 문의는 빠르게 해결하고, 사람의 판단이나 실제 조치가 필요한 업무는 필요한 정보를 갖춘 상태로 담당자에게 연결하는 것을 목표로 한다.

### Goal

- 사내 Guide 기반 IT 문의 1차 대응
- 부족한 정보에 대한 추가 질문 및 적절한 처리 방향 판단
- 사람의 조치가 필요한 문의를 실제 업무 프로세스로 연결
- 담당자의 해결 경험을 다시 사내 지식으로 축적

## 4. Target User

### 👤 일반 임직원

IT 문제를 문의하고 AI로부터 해결 방법을 안내받는다.

AI만으로 해결되지 않는 경우 담당자에게 연결하고, 이후 처리 상태와 결과를 확인한다.

**Needs**

- 담당자를 몰라도 바로 문의하고 싶다.
- 간단한 문제는 빠르게 해결하고 싶다.
- 해결되지 않는 문제는 적절한 담당자에게 연결하고 싶다.
- 요청 이후 진행 상황을 확인하고 싶다.

### 🛠 IT 운영 담당자

AI가 해결하지 못했거나 실제 조치가 필요한 Ticket을 전달받아 처리한다.

**Needs**

- 반복적인 단순 문의를 줄이고 싶다.
- 필요한 정보가 정리된 요청을 받고 싶다.
- 실제 조치가 필요한 업무에 집중하고 싶다.

### ⚙️ 관리자

전체 문의 및 Ticket 현황을 관리하고 사용자·권한·Guide를 관리한다.

담당자가 해결한 사례를 검토하여 새로운 Guide로 활용할 수 있다.

## 5. 핵심 서비스 Flow

### 기본 문의 Flow

```
로그인
  ↓
IT 문의
  ↓
문의 명확성 확인
  ↓
필요 시 추가 질문
  ↓
통합 검색
(Guide + 과거 유사 Ticket)
  ↓
문의 유형·긴급도 분류
  ↓
처리 방향 판단
```

### Case A. AI로 해결된 경우

```
처리 방향 판단
  ↓
AI 답변 가능
  ↓
근거 기반 AI 답변
  ↓
해결 여부 확인
  ↓
해결
  ↓
종료
```

### Case B. 사람의 조치가 필요한 경우

```
담당자 처리 필요 / AI 답변 후 미해결
  ↓
담당자 배정 제안
  ↓
사용자 선택
  ↓
Ticket 초안
  ↓
사용자 확인·수정
  ↓
Jira Ticket 생성
  ↓
담당자 처리
  ↓
처리 결과 안내
```

> **Ticket은 AI의 판단만으로 즉시 생성하지 않는다.**
> 
> 
> 담당자 배정을 사용자가 선택하고 Ticket 초안을 확인한 후 Jira Ticket을 생성한다.
>

## 6. 핵심 기능 및 서비스 특징

### ① Guide 기반 AI 문의 대응

사용자의 자연어 문의를 이해하고, 필요한 정보가 부족한 경우 추가 질문을 통해 문의 내용을 명확하게 한다.

이후 사내 Guide와 과거 유사 Ticket을 검색하고, 검색 결과를 바탕으로 **문의 유형과 긴급도 및 처리 방향을 판단**한다.

AI가 답변 가능한 문의는 사내 Guide를 기반으로 **근거와 함께 해결 방법을 안내**한다.

### ② 권한을 고려한 정보 검색

문의와 관련된 **사내 Guide와 과거 유사 Ticket을 통합 검색**한다.

사내 Guide 검색 시 사용자의 부서와 접근 권한을 고려하여 **접근 가능한 Guide만 검색 대상**으로 사용한다.

검색 결과는 문의 유형·긴급도 및 처리 방향 판단과 AI 답변의 근거로 활용한다.

### ③ AI와 사람의 업무 연결

AI가 해결하기 어려운 문제나 승인·실제 시스템 조치가 필요한 요청은 담당자 배정을 제안한다.

사용자가 담당자 배정을 선택하면 필요한 정보를 기반으로 Ticket 초안을 작성하고, **사용자의 최종 확인 후 Jira Ticket으로 연결**한다.

### ④ 처리 상태 및 결과 연결

Ticket 생성으로 끝나지 않고 담당자의 실제 처리 과정과 결과를 사용자에게 연결한다.

이를 통해 사용자는 자신의 요청이 현재 어떤 상태인지 확인할 수 있다.

### ⑤ 해결 경험의 Knowledge화

기존 Guide만으로 해결하지 못한 문제를 담당자가 해결한 경우, 해당 해결 사례를 관리자가 검토하여 새로운 Guide로 활용할 수 있다.

```
담당자 해결
  ↓
관리자 검토
  ↓
Guide화
  ↓
RAG Knowledge 반영
  ↓
다음 유사 문의에 활용
```

이를 통해 담당자의 해결 경험을 조직의 IT 지원 지식으로 지속적으로 축적한다.

## 7. 프로젝트 구현 범위

이번 프로젝트에서는 다음 **End-to-End Flow가 실제로 동작하는 것**을 목표로 한다.

> **로그인 → IT 문의 → 문의 명확성 확인 및 추가 질문 → 통합 검색 → 문의 유형·긴급도 분류 → 처리 방향 판단 → AI 답변 → 해결 여부 확인 → 필요 시 담당자 배정 제안 → Ticket 초안 → 사용자 확인 → Jira 생성 → 담당자 처리 및 결과 안내**
> 

### 핵심 구현 영역

- AI 기반 IT 문의 대응
- 사내 Guide 기반 RAG
- 사용자 권한을 고려한 검색
- HITL(Human-in-the-Loop)
- Jira 연동
- Ticket 처리 상태 관리
- AI / RAG 평가

### 구현 제외 범위

- 실제 PC 원격제어 및 자동 복구
- AI의 독자적인 권한 승인
- 복잡한 전자결재 시스템
- 실제 기업 내부 데이터
- Mobile App / Voice Interface

> 세부 MVP 기능, 기능별 우선순위 및 제품 정책은 **PRD에서 정의한다.**
>

## 8. 기대 효과

ITssue는 반복적인 IT 문의를 AI가 1차 대응하고, 실제 조치가 필요한 업무는 담당자에게 연결함으로써 **사용자의 문제 해결 경험과 IT 운영 효율을 함께 개선**하는 것을 목표로 한다.

| 대상 | 기대 효과 |
| --- | --- |
| **일반 임직원** | Guide나 담당자를 직접 찾는 과정을 줄이고, 하나의 Flow에서 문의부터 처리 결과까지 확인할 수 있다. |
| **IT 운영 담당자** | 반복적인 단순 문의는 AI가 1차 대응하고, 실제 조치가 필요한 문의는 필요한 정보가 정리된 상태로 전달받아 업무 부담을 줄일 수 있다. |
| **관리자** | 문의 및 Ticket 처리 현황을 확인하고, 반복적으로 발생하는 문의와 해결 사례를 사내 Guide로 관리할 수 있다. |
| **조직** | 담당자의 해결 경험을 Knowledge로 축적하여 반복 활용하고, 개인에게 분산된 IT 업무 지식을 조직의 자산으로 전환할 수 있다. |

### 확장 가능성

ITssue는 사내 IT 문의를 대상으로 시작하지만,

> **사내 Knowledge 검색 → AI 1차 대응 → 담당자 업무 연결 → 처리 결과의 Knowledge화**
> 

라는 구조를 기반으로 한다.

따라서 향후 충분한 사내 Knowledge와 업무 Process가 확보될 경우 **인사·총무·구매 등 다른 사내 지원 업무로 적용 범위를 확장할 수 있다.**

이를 통해 단순 IT 문의 Chatbot을 넘어, **반복적인 사내 문의와 실제 업무 처리를 연결하는 Enterprise AI Agent로의 확장 가능성**을 가진다.
