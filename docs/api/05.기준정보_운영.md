# API 명세서 — 기준 정보·운영 (RF, OP)

> **문서 상태:** Draft v0.2
>
> **기준:** [07. API 설계서](../07.API_설계서.md) v0.2 · [06. 테이블 설계서](../06.테이블_설계서.md) v0.7
>
> **대상 테이블:** `categories`, `inquiry_types`, `support_groups`, `support_group_members`, `member_skills`, `departments`, `inquiries`, `tickets`, `audit_logs`, `llm_calls`

---

## 0. 읽는 법

- 경로는 Base URL `/api/v1` 이후 부분이다.
- 표의 **컬럼**은 테이블 설계서의 컬럼이다. `(파생)`은 테이블 컬럼이 아닌 계산값이다.
- **공통 에러는 API별 표에서 생략한다**: `401 UNAUTHORIZED`, `401 TOKEN_EXPIRED`, `403 AUTH_ACCOUNT_INACTIVE`, `403 AUTH_PASSWORD_CHANGE_REQUIRED`, `422 VALIDATION_ERROR`, `429 TOO_MANY_REQUESTS`, `500 INTERNAL_ERROR`
- 기준 정보는 건수가 적어 페이지 없이 `{ "items": [...] }`로 준다.
- 참조 객체 `GroupRef`·`UserRef`는 [02. 문의·상담](02.문의_상담.md) 2.1을 따른다.

## 2. 운영 (OP)

### 2.1 집계 공통 규칙

| 항목 | 규칙 |
|---|---|
| 기간 | `from`·`to`(date, KST) 포함. 기본 최근 30일(오늘 포함). 최대 1년 |
| 기준 시각 | 문의는 `inquiries.created_at`, 접수는 `tickets.created_at` |
| AI 해결 | `inquiries.status = AI_RESOLVED`. **담당자 처리 완료(`CLS`)와 합산하지 않는다** (SRS ADMIN-03) |
| 확인 필요 | `jira_sync_status`, `assign_status`, `transition_status` 중 하나가 `NEEDS_ADMIN` |
| 추이 | `interval`: `DAY` / `WEEK` / `MONTH`. 기본 `DAY` |

공통 Query

| 파라미터 | 타입 | 필수 | 설명 |
|---|---|---|---|
| from | string(date) | | 시작일 |
| to | string(date) | | 종료일 |
| interval | string | | 추이 단위 |

공통 Errors

| HTTP | code | 조건 |
|---|---|---|
| 400 | `INVALID_REQUEST` | `from`이 `to`보다 늦음, 기간 1년 초과 |
| 422 | `VALIDATION_ERROR` | 날짜 형식·`interval` 값 오류 |

`WorkCounts` — 업무 상태별 접수 수

| 필드 | 타입 | 설명 |
|---|---|---|
| rdy | number | `work_status = RDY` |
| wip | number | `WIP` |
| fin | number | `FIN` |
| cls | number | `CLS` |

### OP-03 AI 사용 현황

`GET /dashboard/ai-usage` · 권한: ADMIN · 요구사항: LOG-02

`llm_calls`와 `inquiries`를 집계한다. 원본 호출 기록은 주지 않는다.

**Query**: 2.1 공통 Query

**Response** `200 OK` (모든 필드 파생)

| 필드 | 타입 | 설명 |
|---|---|---|
| period | `{ from, to, interval }` | |
| totals | object | 아래 표 |
| byPurpose | array | `{ purpose, callCount, failedCount, avgLatencyMs, inputTokens, outputTokens }` (`llm_calls.purpose`) |
| byModel | array | `{ model, adapter, callCount, inputTokens, outputTokens, estimatedCost }` |
| trend | array | `{ date, aiConsultationCount, aiResolvedCount, callCount, estimatedCost }` |

`totals`

| 필드 | 설명 |
|---|---|
| aiConsultationCount | AI 상담 건수 (기간 내 문의 수) |
| aiResolvedCount | AI 해결 수 |
| aiResolvedRate | AI 해결률 = AI 해결 / AI 상담 (0~1, 소수 셋째 자리) |
| callCount | 모델 호출 수 |
| failedCount | 실패 호출 수 (`success = false`) |
| avgLatencyMs | 평균 응답 시간 |
| inputTokens / outputTokens | 토큰 합계 |
| estimatedCost | 추정 비용 (USD). 모델별 단가 설정 × 토큰 |
| budget | 기간 예산 (USD, 설정값). 없으면 `null` |
| budgetUsageRate | `estimatedCost / budget`. `budget`이 없으면 `null` |

```json
{
  "period": { "from": "2026-10-01", "to": "2026-10-21", "interval": "DAY" },
  "totals": {
    "aiConsultationCount": 160, "aiResolvedCount": 92, "aiResolvedRate": 0.575,
    "callCount": 812, "failedCount": 6, "avgLatencyMs": 2140,
    "inputTokens": 1532000, "outputTokens": 214000,
    "estimatedCost": 7.81, "budget": 30.0, "budgetUsageRate": 0.26
  },
  "byPurpose": [ { "purpose": "CLASSIFY", "callCount": 310, "failedCount": 2, "avgLatencyMs": 1320, "inputTokens": 520000, "outputTokens": 41000 } ],
  "byModel": [ { "model": "claude-sonnet-5-5", "adapter": "Claude", "callCount": 812, "inputTokens": 1532000, "outputTokens": 214000, "estimatedCost": 7.81 } ],
  "trend": [ { "date": "2026-10-21", "aiConsultationCount": 9, "aiResolvedCount": 5, "callCount": 44, "estimatedCost": 0.41 } ]
}
```
