# 프론트 → 백엔드 연동 요청 목록

프론트엔드를 서버 API에 연결하면서 **서버에 없거나 화면과 맞지 않는 부분**을 한곳에 모은 문서예요.
화면 PR마다 여기에 항목을 더하거나 상태를 고치고, PR 본문에는 "요청 R-NN 참고"처럼 번호만 적어요.

- 프론트는 시안(`design/ITssue-Prototype.html`)을 기준으로 구현하고, 서버에 없는 기능은 모의(mock) 모드에서만 동작하게 두거나 서버 모드에서 안내만 보여 줘요.
- 근거 문서: `01~05` 명세, `07.API_설계서.md`. 항목의 API 번호(TK-05 등)는 그 문서의 번호예요.
- **상태**: 요청 전 → 요청함 → 반영됨(서버에 올라감) → 프론트 적용(화면 연결 끝) / 보류(시안 쪽을 바꾸기로 함)

> 갱신 규칙: ① 새 화면 PR에서 서버와 안 맞는 점이 생기면 이 표에 한 줄 추가 ② 백엔드가 반영하면 상태를 "반영됨"으로 바꾸고, 프론트가 연결하는 PR에서 "프론트 적용"으로 바꿈 ③ 마지막에 갱신 이력에 한 줄 적기

## 6. 요청은 아니지만 알아 둘 것

- 문의자에게 메시지(MSG-01)와 Slack 미리보기는 시연용 목업으로 확정이라 서버 연결처가 없어요(화면에 "제안" 표시 유지).
- 로컬에서 AI 답변을 보려면 임베딩 모델 폴더(`models/bge-m3`)와 `uv sync --extra embedding`이 필요해요. 없으면 가이드 검색 단계에서 503(`AI_UNAVAILABLE`)이 나고 화면은 담당자 연결 안내를 보여 줘요.
- 계정 관리 추가 폼의 직급은 서버 값과 맞고, Slack ID 입력은 화면에 없어요.
