# 프론트 → 백엔드 연동 요청

담당은 A~F 분장에 따른 **제안**입니다. 우선순위는 [SRS](../03.요구사항정의서(SRS).md)와 연결한 것이며, “관련”은 요청 전체의 필수 확정을 뜻하지 않습니다. 상태는 기존 기록을 유지했습니다. 모의는 시연 데이터, 서버 모드는 실제 API를 사용합니다.

기록 기준: 기존 연동 요청 문서와 코드·명세 확인 내용을 정리한 것으로, 전 항목을 실제 화면에서 재현한 테스트 결과표는 아닙니다. 담당·협업 배분은 역할에 따른 제안이고, 100건 초과 시 누락 등은 구조상 예상되는 영향입니다. 원문의 미구현·배포 상태는 이번 편집에서 재검증하지 않았습니다.

## R-01. 대시보드·통계 집계 API(OP-01·OP-02) 구현

- **담당:** 민경님: 집계 API와 추가 지표 제공 / 협업: 나영님
- **우선순위:** Should / ADMIN-03·05 · **상태:** **요청 전**
- **요청:** 대시보드·통계용 집계 API(OP-01·02)를 구현해 주세요. 처리 대기(RDY) 건수, 긴급·높음 미해결 접수의 상위 N건, Jira 알림 건수, 연동·배정 문제의 원인별 건수, 팀·개인별 분포, 접수일 기준 해결 완료 추이가 필요합니다.
- **현재 이슈 사항:** 목록을 여러 번 요청하고 최대 100건으로 계산. 100건을 넘으면 누락·통계 오차가 생길 수 있음
- **참고 화면:** [관리자 대시보드](../../frontend/src/views/admin/DashView.tsx) · [관리자 통계](../../frontend/src/views/admin/AdminStatsView.tsx) · [내 대시보드](../../frontend/src/views/staff/MyDashView.tsx) · [운영 현황](../../frontend/src/views/admin/OpsView.tsx) · [내 통계](../../frontend/src/views/staff/StatsView.tsx)
