# 서버 연결 화면 시연 문구 점검

기준: `VITE_USE_MOCK=false`, `VITE_SERVER_INTAKE=true`. 영역별 `VITE_USE_MOCK_*`가 별도로 덮어쓰지 않는 환경이다. 프론트 화면·API 분기와 백엔드 소스를 점검했으며, 배포 서버의 실제 응답과 저장된 데이터 전체를 조회한 결과는 아니다.

## 수정한 내용

- **과거 처리 사례:** 실제 서버 출처에도 붙던 ‘시연용 가상 데이터’를 제거했다. 서버가 주는 사례 번호(`location`)와 참고 본문(`excerpt`)을 표시한다. 본문이 없으면 상세 내용이 제공되지 않았다고 안내하며 임의 사례로 채우지 않는다.
- **문의 내역:** 종료된 미해결·미접수 문의도 이어갈 수 있다는 오해를 없애고, 종료된 문의는 기록 조회만 가능하며 추가 문의는 새 문의로 시작하도록 안내했다.
- **민감정보 안내:** 서버와 프론트 모의 응답의 ‘비밀번호 재설정 포털’을 ‘실제 사용 중인 비밀번호라면 해당 서비스에서 비밀번호를 변경해 주세요.’로 통일했다. 기존 대화에 이미 저장된 안내는 소급 변경하지 않는다.

## 사용자 판단 전 유지한 항목

| 위치 | 서버 연결 시 동작 | 판단할 내용 |
| --- | --- | --- |
| 로그인 하단 ‘ICT 가상 기업 프로토타입’ | 모드와 관계없이 표시 | 데이터 출처 표시가 아니라 프로젝트 소개 문구다. 삭제·교체 여부 결정 전 유지했다. |
| 로그인 전 질문 칩·답변 | `api/consult.ts`의 공개용 고정 답변. 서버 가이드 조회·AI 호출 없음 | 앞서 합의한 방식이다. 실제 AI 답변 기능은 아니며 임의로 제거하지 않았다. |
| AI 운영 예산 | 서버 `totals.budget` 값을 사용. 현재 월 기준 150 USD를 선택 기간에 비례 계산 | 서버 기준값이지만 실제 호출 차단 기능은 아니다. 사용자 요청으로 추가 설명 문구는 화면에서 제거했다. 기준값은 `backend/app/constants/llm.py`의 코드 상수이며 DB 쿼리로 바꾸는 설정이 아니다. 설정 화면이나 차단 기능은 추가하지 않았다. |

## 서버 모드에서 숨겨지는 항목

- 로그인 시연 계정 비밀번호·바로 로그인: `USE_MOCK_AUTH`일 때만 표시.
- 문의의 ‘응답 없음 시연’ 조작 버튼: `USE_MOCK_INQUIRY`일 때만 표시.
- 출처 미리보기의 ‘(시연)’: 문의·FAQ가 각각 모의 모드일 때만 표시.
- AI 운영·보안 알림·AI 가이드 제안의 ‘시연 데이터’: 각 영역이 모의 모드일 때만 표시.
- 가이드의 ‘시연용 본문’: 모의 가이드에서만 생성. 서버 조회 실패를 시연 본문으로 대체하지 않는다.
- AI 답변 품질 평가(Golden Set): 고정 예시 데이터는 코드에 남아 있지만 현재 AI 운영 화면에는 노출하지 않는다.

‘AI 가이드 제안’, ‘제안 유형’은 실제 기능·데이터 이름이므로 제거 대상이 아니다. ‘검색 준비 중’도 실제 적재 상태이므로 유지한다. 백엔드 앱 소스에서는 ‘시연용·가상 데이터·모의 데이터·제안 기능·프로토타입·샘플 데이터’ 안내가 추가로 발견되지 않았다. DB·데이터셋 원문까지 없음을 보장하는 뜻은 아니다.

## 검증

- 프론트 빌드·린트 통과, 98개 파일 / 721개 테스트 통과.
- 백엔드 민감정보 테스트 60개 통과.
- 로컬 Chrome에서 운영 기록 재진입·수동 조회, 숨긴 탭 조회 중단·복귀 조회, 알림 조회 공유, 담당자 통계 수동 조회를 확인했다. 운영 기록 4개 화면 모드 캡처를 생성했다. 배포 서버의 종단 간 검증과는 구분한다.
