# 보안 검토 질문 시나리오 140개

7개 유형별 감지 대상 12개와 정상 문의 8개입니다. 감지는 사고·위반 확정을 뜻하지 않습니다.
이 문서는 기대 결과이며 실제 LLM 분류 정확도 검증 결과가 아닙니다. 복합 요청은 여러 코드가 함께 나올 수 있습니다.
S01은 긴급 대응·최소 P2, S02~S07은 일반 보안 검토·담당자 연결입니다. 정상 문의는 이 보안 기준에 의한 알림 없이 기존 흐름을 따릅니다.
시나리오 원본은 `tests/fixtures/security_scenarios.json`이며 같은 자료를 실제 모델 평가에도 사용할 수 있습니다.
명백한 요청도 모델 오판으로 누락될 수 있습니다. 프롬프트는 서버의 접근권한·전송정책 검사를 대체하지 않습니다.

## 실제 모델 평가

기본 명령은 외부 호출 없이 자료만 확인합니다. `--live`를 지정할 때만 서버 환경의 LLM 설정으로 평가합니다. 실사용 대화나 인증정보를 넣지 마세요.

```sh
PYTHONPATH=backend python -m app.agent.security_evaluation
PYTHONPATH=backend python -m app.agent.security_evaluation --live --output /tmp/security-evaluation.json
```

결과에는 필수 코드 누락, 정상 문의의 오탐, 긴급 여부 불일치가 기록됩니다. 모델·프롬프트 변경 시 같은 자료로 비교하세요.
